# PullOver X

Based on PullOver Pro by `c1d3rDev`.
Adapted for iOS 14+, added some features, and fixed some known issues.

## 本仓库说明（复刻构建）

本仓库完整复刻 [mlgm66/PullOver-X](https://github.com/mlgm66/PullOver-X)（GPL-3.0），
在其源码基础上**仅新增 GitHub Actions 构建流水线**（`build.sh` 与源码原样保留），
自动产出 `roothide` / `rootless` 两种越狱环境的 .deb 安装包。

- 原项目作者：mlgm（基于 PullOver Pro by c1d3rDev）
- 构建方式：macOS + Xcode 15.4 + roothide/theos，直接运行项目自带 `build.sh`
- 依赖：`com.opa334.altlist`（安装时从源获取）
